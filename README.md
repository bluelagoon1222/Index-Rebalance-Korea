# 지수 정기변경 CHECK (Index-Rebalance-Korea)

정기변경 때 기계적으로 발생하는 패시브 수급을 미리 계산해 두는 사이트입니다.
KOSPI 200·KOSDAQ 150의 편입·편출 후보와, FnGuide 반도체 TOP10처럼 상위 종목 비중을 되돌리는
Cap 리밸런싱의 예상 매수·매도 금액을 매일 자동으로 산출합니다.

- 공개 주소: https://bluelagoon1222.github.io/Index-Rebalance-Korea/
- 갱신: GitHub Actions, 평일 08:20 · 18:40 KST (인증키 불필요)
- 데이터: 네이버 금융(전종목 시가총액·거래대금·ETF 순자산), WiseReport(ETF 구성내역)

## 화면 구성

| 영역 | 내용 |
|---|---|
| 캘린더 | KRX 정기변경(6·12월), FnGuide 섹터 TOP10(4·10월), MSCI(2·5·8·11월), FTSE(3·6·9·12월)의 다음 일정과 D-day |
| 지수 탭 | 추종자금·구성종목 수·예상 매수/매도 합계, 추종자금 가정 조절 입력 |
| 편입·편출 후보 | 시총 순위, 경계선 대비 여유, 예상 비중, 예상 수급, 거래대금 대비 일수 |
| Cap 리밸런싱 | 현재 비중 대 목표 비중, 되돌림에 따른 종목별 매도·매수 예상 금액 |

## 산출 방법

- **예상 수급** = 추종자금 × 비중 변화. 편입은 신규 비중, 편출은 현재 비중, Cap은 목표 비중과 현재 비중의 차이입니다.
- **추종자금**은 해당 지수를 실물 복제하는 ETF의 순자산 합계입니다. 레버리지·인버스는 선물 복제이므로 제외합니다.
  화면의 입력칸에서 인덱스펀드·연금 등을 더해 가정을 바꾸면 모든 금액이 즉시 다시 계산됩니다.
- **거래대금 대비 일수** = 예상 수급 ÷ 최근 20거래일 평균 거래대금.
- **구성종목과 비중**은 지수를 추종하는 대표 ETF가 매일 공시하는 보유내역에서 가져옵니다
  (KOSPI 200 → KODEX 200, KOSDAQ 150 → KODEX 코스닥150, 반도체 TOP10 → TIGER 반도체TOP10).
- **FnGuide 섹터 TOP10 Cap 규칙**: 상위 2종목 각 25%, 나머지 8종목이 50%를 유동시총 가중.
  선정기준일은 3·9월 말 영업일, 변경일은 4·10월 만기 다음 주 첫 영업일.

## 한계

- 지수 심사에 쓰이는 유동시가총액을 공개 경로로 얻을 수 없어 **전체 시가총액을 대용치**로 씁니다.
- 산업군별 누적시총 85%, 최소 상장 6개월 등 세부 요건을 반영하지 않은 **순위 기반 추정**입니다.
  경계에 걸린 종목은 실제 결과가 다를 수 있습니다.
- 캘린더는 공개된 방법론에서 계산한 날짜로, 공휴일이나 거래소 공지에 따라 하루 정도 차이가 날 수 있습니다.
- MSCI·FTSE는 일정만 표시하고 편입·편출 후보는 산출하지 않습니다.

## 파일

```
index.html                    화면 (단일 파일, 외부 라이브러리 없음)
data/latest.json              화면이 읽는 산출물 (자동 생성)
data/status.json              마지막 실행 요약 (자동 생성)
data/state.json               순위 스냅샷 (자동 생성, 삭제해도 재생성)
scripts/collect.py            수집·산출 스크립트
scripts/indices.py            추적 지수와 대표 ETF·Cap 규칙 설정
scripts/calendar_rules.py     정기변경 일정 계산 규칙과 휴장일
scripts/make_sample.py        화면 확인용 샘플 데이터 생성
scripts/test_offline.py       네트워크 없이 전체 흐름을 검증하는 테스트
.github/workflows/update.yml  자동 실행 설정
```

## 추적 지수 추가

`scripts/indices.py` 의 `INDICES` 에 항목을 추가하면 됩니다. 대표 ETF 코드(`etf`)와
추종자금 집계용 이름 패턴(`aum_include`), Cap 규칙(`cap`)만 지정하면 화면에 탭이 하나 늘어납니다.

## 유의사항

본 사이트는 공개된 지수 방법론에서 계산한 참고자료로, 특정 종목의 매매를 권유하지 않습니다.
추정치이며 실제 정기변경 결과 및 수급과 다를 수 있습니다.
